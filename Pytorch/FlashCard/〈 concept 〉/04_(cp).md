```python

```

```text
A) 아무 문제 없이 학습된다.
B) float 레이블을 분류 모델에서 허용하므로 결과가 연속적으로 출력된다.
C) 분류 모델이 정수형 레이블을 요구하므로 런타임 에러가 발생한다.
D) 모델이 자동으로 float 레이블을 one-hot 벡터로 변환한다.
```
?
