(Unsqueeze 문제)다음은 소프트맥스 함수에 입력할 로짓(logit) 벡터와, 타겟 값(정답)을 원소곱(element-wise)하여 손실을 계산하려는 코드이다.
<pre><code class="language-python">
logits = torch.tensor([2.0, 1.0, 0.1])       # shape: (3,)

</code></pre>위 두 텐서의 원소곱을 수행하여 다음과 같은 손실 텐서를 계산하려고 한다:
오류를 해결하기 위해 어떤 텐서에 연산을 적용해야 할까?
?
```python
logits.unsqueeze(1)
```

다음은 RGB 이미지 한 장을 표현하는 텐서입니다.
사람의 시각 특성을 반영한 R/G/B 채널별 가중치를 적용하여,
`흑백(grayscale) 이미지 텐서 (5, 5)`를 구하려고 한다.
<pre><code class="language-python">
import torch
<br>
img_t = torch.randn(3, 5, 5)  # [채널, 높이, 너비]
weights = torch.tensor([0.2126, 0.7152, 0.0722]) # 가중치 텐서
</code></pre>
다음 빈칸을 채워 grayscale 이미지를 계산해라.
```python
gray = (img_t * ____________________).sum(dim=___)
```
?
```python
gray = (img_t * weights.view(3, 1, 1)).sum(dim=0)
```
해설: `weights.view(3, 1, 1)을 통해 (3,) 크기의 1D 가중치 벡터를 (3, 1, 1)로 브로드캐스팅이 가능하게 만들어 준다.`

다음은 모델의 예측값(pred)과 정답(target) 텐서를 곱해 손실을 계산하려는 상황이다.
하지만 두 텐서의 차원이 달라 연산이 실패한다.
이에 따라, target 텐서를 pred의 shape과 정렬되도록 자동으로 `reshape` 및 `broadcast` 가능하도록 확장하려고 한다.
```python
import torch

pred   = torch.randn(2, 1, 3, 1)
target = torch.randn(2, 3)  # [배치, 클래스]
```
두 텐서를 곱셈하기 위해 target을 pred의 shape에 맞게 자동 정렬하려 한다.
**다음 코드를 완성**해라:
<pre><code class="language-python">
target_aligned = target.<strong>align_as(pred)</strong>
loss = (pred * target_aligned).sum()
</code></pre>
