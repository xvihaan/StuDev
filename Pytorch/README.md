# 파이토치 딥러닝 마스터
Pytorch 스터디를 위한 READ & CODE

## READ
주마다 1장씩 각 챕터마다 숙지한다.

모르는 개념이 있다면, 질문방에다가 올릴 것

모르는 개념과 꼭 유용한 내용은 `Flash Card` 학습으로 숙지

## CODE
각 챕터에 있는 실습 코드를 꼭 `스스로` 실행해보자.

실행 실습은 빠지지 않고 업로드 할 것.

모르는 코드와 꼭 유용한 코드는 `Flash Card` 학습으로 숙지

## FLASH CARD
Obsidian으로 Space Repetition 플러그인을 사용한 `FLASH CARD` 학습.

질문은 앞면, 답은 뒷면으로 학습하는 방식으로 꾸준한 기억력에 도움이 되는 학습 방식
